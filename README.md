# 📊 HR Analytics Dashboard – Power BI

## 📌 Project Overview

This project is an **HR Analytics Dashboard** developed using **Microsoft Power BI** to analyze employee data and provide meaningful insights into workforce performance, employee demographics, attrition, and other HR-related metrics.

The dashboard helps HR teams and management understand employee trends and make data-driven decisions.

## 🎯 Project Objectives

- Analyze employee demographics and workforce information.
- Monitor employee attrition and retention.
- Identify trends in employee performance and satisfaction.
- Analyze employee distribution across departments and job roles.
- Create interactive dashboards for HR decision-making.
- Present important HR KPIs in an easy-to-understand format.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Excel / CSV**
- **Data Visualization**

## 🧹 Data Cleaning & Transformation

The dataset was prepared using **Power Query**.

The main data-cleaning activities included:

- Checking and handling missing values.
- Removing duplicate records.
- Correcting data types.
- Renaming columns where required.
- Standardizing data values.
- Creating calculated columns.
- Transforming and preparing data for analysis.

## 📈 Key HR KPIs

The dashboard includes important HR metrics such as:

- Total Employees
- Total Attrition
- Attrition Rate
- Average Employee Age
- Average Salary
- Employee Count by Department
- Employee Count by Job Role
- Employee Count by Gender
- Employee Count by Education
- Employee Attrition by Department
- Employee Attrition by Job Role

## 📊 Dashboard Features

The Power BI dashboard provides interactive analysis using:

- KPI Cards
- Bar Charts
- Column Charts
- Pie / Donut Charts
- Tables
- Slicers
- Filters
- Interactive visualizations

Users can filter the dashboard based on different employee attributes and analyze HR trends.

## 🔍 Key Insights

Some of the insights that can be obtained from the dashboard include:

- Departments with higher employee attrition.
- Job roles with higher attrition rates.
- Employee distribution across departments.
- Employee distribution by gender and age group.
- Salary trends across different job roles.
- Workforce composition and employee trends.
